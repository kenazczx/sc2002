# Stage 3 reproducible VICTORY run, base setting, default seed 42.
#   java -cp out app.RestaurantRush --script runs/victory.txt
#
# Line-up: C1 Regular, C2 Critic, C3 Regular, C4 VIP, C5 Regular, C6 Regular.
# This run exercises every Stage 3 feature and reproduces both arithmetic examples
# in Section 4.3 of the brief:
#   - the Host seats a customer and the Waiter takes their order in the same turn;
#   - C1 orders the Salad + Pasta combo, $24.30 for 3 preparation units;
#   - the Critic orders Burger + Pasta, the most demanding item on the menu;
#   - Happy Hour is switched on at the start of turn 10 and runs for two turns;
#   - the VIP's Burger is billed $15.00 x 0.9 x 0.8 = $10.80;
#   - C3's order, taken on turn 8 at $15.00, is paid on turn 11 while Happy Hour runs
#     and still costs $15.00, because the price is fixed when the order is taken;
#   - C5's order on turn 13 is at full price again, because Happy Hour has expired.
#
# Prompt order within a turn: Happy Hour, Host, Waiter, Chef. A staff member whose
# only legal task is to wait is not asked, so those turns consume no line.
#
seat 1          # T1  Host
order 1         # T1  Waiter    Salad + Pasta, 3 units
prep 1          # T1  Chef      1/3
prep 1          # T2  Chef      2/3
prep 1          # T3  Chef      3/3, READY
seat 2          # T4  Host      the Critic
order 2         # T4  Waiter    THE DECISIVE CHOICE: order for the Critic before serving C1.
                #               It costs C1 two turns of satisfaction but is the only way to
                #               serve the Critic within three turns, which earns the +10 review.
prep 2          # T4  Chef      1/3
serve 1         # T5  Waiter
prep 2          # T5  Chef      2/3
prep 2          # T6  Chef      3/3, READY
serve 2         # T7  Waiter    three turns after arrival: favourable review
seat 3          # T8  Host
order 3         # T8  Waiter
prep 3          # T8  Chef      Burger, READY in one unit
serve 3         # T9  Waiter
y               # T10 Happy Hour ON: 20% off new orders, 15 goodwill per active turn
seat 4          # T10 Host      the VIP
order 4         # T10 Waiter    $15.00 x 0.9 x 0.8 = $10.80
prep 4          # T10 Chef
serve 4         # T11 Waiter    goodwill has already carried the VIP back to 100
seat 5          # T13 Host      Happy Hour has expired by now
order 5         # T13 Waiter    Salad at the full $9.00
prep 5          # T13 Chef
serve 5         # T14 Waiter
seat 6          # T16 Host      C6 cannot finish paying, but is seated and served anyway
order 6         # T16 Waiter
prep 6          # T16 Chef
prep 6          # T17 Chef
serve 6         # T18 Waiter
