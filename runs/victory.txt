# Line-up: C1 Regular, C2 Critic, C3 Regular, C4 VIP, C5 Regular, C6 Regular.
# This line maximises the number of paying customers: five pay, for $79.20.
# It deliberately gives up the Critic's favourable review, because serving the
# Critic within three turns would need the Waiter on turns 4 and 5, which holds
# C1's table until turn 8 and costs the fifth payment. See runs/critic-first.txt.
#
seat 1          # T1  W
order 1         # T2  W   C1 chooses Pasta, two preparation units
prep 1          # T2  C
prep 1          # T3  C   READY at the end of turn 3
serve 1         # T4  W
seat 2          # T5  W   the Critic has already lost 12
order 2         # T6  W   a Critic always orders the most demanding dish
prep 2          # T6  C
seat 3          # T7  W
prep 2          # T7  C
serve 2         # T8  W   served four turns after arrival, so the review is unfavourable
order 3         # T9  W
prep 3          # T9  C
serve 3         # T10 W   no table is free yet, so the VIP cannot be seated this turn
seat 4          # T11 W
order 4         # T12 W   VIP pays 90%: $18.00 becomes $16.20
prep 4          # T12 C
seat 5          # T13 W   seating C5 now is what makes the fifth payment possible
prep 4          # T13 C
order 5         # T14 W
prep 5          # T14 C
serve 4         # T15 W
prep 5          # T15 C
serve 5         # T16 W
wait            # T18 W   C6 arrived on turn 16 and cannot finish paying
